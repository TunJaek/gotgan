## 2. 개인정보의 수집 방법과 처리 목적

운영자는 회원이 가입, 자료 보완, 매물 등록, 문의, 신고 및 서비스 이용 과정에서 입력하거나 제출한 정보와 서비스 이용에 따라 생성되는 기록을 처리합니다. 사업자 상태정보는 국세청 사업자 상태조회 API를 통해 확인합니다.

주요 처리 목적은 회원 식별과 로그인, 휴대폰 본인인증, 사업자 자격 심사, 매물 게시와 연락 기능 제공, 계정 복구, 신고 처리 및 서비스 오남용 대응입니다.

이메일과 업종은 선택 항목입니다. 이를 입력하지 않아도 필수정보를 통한 가입 심사를 받을 수 있습니다. 연락처 공개 동의는 별도로 선택할 수 있으며, 동의하지 않아도 매물 등록과 1:1 문의 기능을 이용할 수 있습니다.

## 4. 연락처의 제3자 제공 및 사업자 상태조회

### 가. 매물 연락처의 제3자 제공

매물 연락처는 기본 비공개이며, 판매 회원이 매물별로 별도의 선택 동의를 한 경우에만 다음과 같이 제공합니다.

| 항목 | 내용 |
|---|---|
| 제공받는 자 | 해당 매물에서 ‘연락처 보기’를 실행한 곳간의 승인 회원 |
| 제공 목적 | 해당 매물에 관한 거래 문의·협의 |
| 제공 항목 | 가입 시 인증한 휴대전화번호 |
| 제공받는 자의 보유·이용기간 | 거래 상담 종료 시까지. 다만, 매물 종료 후 30일을 초과하여 보유할 수 없습니다. 관계 법령상 별도의 보존 의무가 있는 경우에는 그 범위에서만 보존할 수 있습니다. |
| 동의 거부 시 영향 | 연락처 직접 공개 기능만 이용할 수 없으며, 매물 등록과 1:1 문의는 이용할 수 있습니다. |
| 철회 방법 | 해당 매물의 연락처 공개 설정을 비공개로 변경 |
| 제공 관련 기록 | 매물별 동의·철회 시각과 문구 버전, 열람 회원·매물·시각 |

연락처 공개를 철회하면 이후 신규 열람이 중단됩니다. 이미 번호를 열람한 회원의 저장 내용까지 자동 삭제되지는 않습니다. 제공받은 회원에게는 거래 목적 외 이용·무단 전달·배포 금지와 보유기간 준수 의무가 적용됩니다.

### 나. 국세청 사업자 상태조회

가입 시 사업자 상태를 확인하고, 운영자가 수동으로 존속 점검을 실행할 때 국세청 사업자 상태조회 API를 사용합니다.

| 항목 | 내용 |
|---|---|
| 조회 서비스 | 국세청 사업자등록정보 상태조회 API |
| 전송 대상 | 국세청 사업자 상태조회 서비스 |
| 전송 항목 | 사업자등록번호 |
| 전송 목적 | 계속사업자 여부 등 사업자 상태 확인 |
| 전송 시점 | 가입 시 및 운영자의 수동 존속 점검 시 |
| 곳간의 결과 보유기간 | 제3절의 사업자 상태조회 항목에 따름 |
| API 제공기관의 요청정보 보유기간 | [API 제공기관의 요청정보 보유기간 확인 후 기재] |

상태조회 요청을 위해 사업자등록증 파일이나 휴대전화번호를 전송하지 않습니다.

### 다. 법령에 따른 제공

운영자는 관계 법령에 근거한 적법한 요청이 있는 경우 요청의 근거와 범위를 확인하여 필요한 개인정보를 제공할 수 있습니다.

## 7. 탈퇴 시 처리와 개인정보 파기

### 가. 현재 탈퇴 시 처리

회원이 비밀번호를 재확인하여 탈퇴하면 즉시 처리되며 복구할 수 없습니다.

| 대상 | 탈퇴 시 처리 |
|---|---|
| 상호·대표자명·휴대전화번호·이메일·업종 | 회원정보에서 삭제 |
| 사업자등록번호 | 회원정보에서 비움 |
| 사업자등록증 파일 | 삭제 |
| 회원 행 | 남음 |
| 매물·사진 | 매물은 숨김 처리되고 내용은 보관 |
| 기존 대화 | 상대방에게 남으며 발신자는 ‘탈퇴한 회원’으로 표시 |
| 신고·심사·운영 기록 | 탈퇴 즉시 삭제되지 않음 |

‘탈퇴한 회원’으로 표시하거나 회원정보 일부를 삭제하는 것만으로 매물·메시지·기록에 포함된 모든 개인정보가 제거되는 것은 아닙니다.

### 나. 보유기간 종료 후 파기 절차

보유기간이 끝난 정보는 매일 한 번 자동으로 삭제합니다. 전자적 자료는 복구 또는 재생할 수 없도록 적절한 삭제 방법을 적용하고, 파일과 DB 기록의 연결정보도 함께 정리합니다.

**[제안]** 진행 중인 구체적인 신고·분쟁 때문에 추가 보관이 필요한 경우 해당 사건에 필요한 정보만 별도로 구분하고, 보관 사유와 종료 시점을 기록합니다. 기본안은 사건 종결 후 90일 이내 삭제이며, 추가 보관의 적법한 근거가 없는 정보는 원래 보유기간에 따라 삭제합니다.

관계 법령상 보존 의무가 있는 정보는 해당 항목과 법정기간을 확인하여 다른 정보와 분리해 보관합니다.

백업에 남은 삭제 대상 정보의 삭제·덮어쓰기 주기 및 복원 시 재삭제 절차: **[제안·확정 필요] 백업 도입 및 보존기간 확정 시 함께 정합니다.**

## 8. 정보주체의 권리와 행사 방법

① 정보주체는 자신의 개인정보에 대한 열람, 정정·삭제, 처리정지 및 동의 철회를 요청할 수 있습니다.

② 요청은 [문의 이메일] 또는 [전화번호]로 접수할 수 있습니다. 운영자는 요청자의 본인 여부와 필요한 요청 범위를 확인한 후 관계 법령에 따라 처리하고 결과를 알립니다.

③ 연락처 공개 동의는 매물의 연락처를 비공개로 변경하여 철회할 수 있습니다. 회원 탈퇴는 비밀번호 재확인을 거쳐 즉시 처리됩니다.

④ 이용정지 중에는 서비스 내 탈퇴 기능을 사용할 수 없습니다. 이용정지 상태에서도 개인정보 권리행사 요구는 제1절의 문의처로 접수할 수 있습니다.

⑤ 다른 사람의 권리를 침해하거나 관계 법령상 제한 사유가 있는 경우에는 요청의 전부 또는 일부가 제한될 수 있으며, 이 경우 해당 사유를 안내합니다.

⑥ 대리인을 통한 권리행사의 경우 본인과 대리권 확인에 필요한 자료를 요청할 수 있습니다.
